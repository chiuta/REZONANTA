# REZONANȚA

[English](README.md) · [Română](README.ro.md) · **Français** · [Italiano](README.it.md) · [Español](README.es.md) · [Português](README.pt.md) · [Deutsch](README.de.md) · [Magyar](README.hu.md)

Comment se faire écouter — guide et outils pour la communication et les médias. Un seul fichier HTML, hors ligne, sans compte.

**[Ouvrir l’application →](https://rezonanta.chiuta.ro/)**

_Version : 1.0 · Dernière mise à jour : 2026-11-06_

## Fonctionnalités

- 12 principes pour se faire écouter, chacun avec un test pratique.
- Maison du message, recommandation de canaux et générateur de communiqué de presse.
- Fiche d’interview, analyseur de clarté, plan de communication modifiable (export texte/CSV) et étapes de la première heure de crise.
- Tout reste dans le navigateur ; export et import JSON.

## Utilisation

Ouvrez la page en ligne, ou téléchargez `index.html` et ouvrez-le dans un navigateur récent. Aucune installation, aucun build.

## Limites

- L’interface n’est pour l’instant qu’en roumain.
- L’analyseur de clarté est une heuristique et les scores des canaux sont indicatifs. Les textes générés sont des points de départ : vérifiez faits, chiffres et noms avant de publier.

## Confidentialité

Tout reste dans votre navigateur (localStorage / IndexedDB) ; pas de compte, pas de suivi. Aucune requête réseau.
